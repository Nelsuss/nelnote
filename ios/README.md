# NEL NOTE 아이폰 앱 (IPA 빌드용)

이 폴더는 웹 화면(`../index.html`)을 아이폰 앱으로 감싸는 프로젝트예요.
맥이 없어도 GitHub Actions 가 맥 서버에서 서명 없는 IPA를 만들어 줘요.

## IPA 만들기

1. 저장소의 **Actions** 탭 → **Build iOS IPA** → **Run workflow**
2. 5~10분 뒤 초록 체크가 뜨면 저장소 오른쪽 **Releases** 의 `NEL NOTE iOS (최신)`에서 `NelNote.ipa` 받기
3. 아이폰에서 이 파일을 쓰시는 서명 앱(AltStore 등)으로 열어 설치

빨간 X 가 뜨면 실패한 단계를 눌러 나오는 오류 내용을 알려 주세요.

## 알아 두기

- 기록은 앱 안 파일에 저장돼요. 앱을 지우면 함께 지워지니 설정의 백업을 가끔 해 두세요.
- 웹 앱(홈 화면에 추가)에 쌓은 기록은 자동으로 옮겨지지 않아요. 웹 앱에서 **백업 보내기** → IPA 앱에서 **불러오기**로 옮기세요.
- 화면(`index.html`)을 고친 뒤에는 IPA 를 다시 만들어야 앱에 반영돼요. 웹 앱은 올리기만 하면 돼요.
